# 数据约定

必填：`title`（非空文本）、`lat`（-90..90）、`lng`（-180..180）。数字字符串可用于 CSV。0,0 是合法坐标，不会被改为国家中心。

可选字段：

| 字段 | 格式与含义 |
|---|---|
| id | 文本或数字，批次内唯一；建议 API 提供稳定 ID，缺失时用行号 |
| category | 任意分类名；缺失为“未分类”，不限定业务类型 |
| location / country | 展示地点名，不用于推断或覆盖坐标 |
| timestamp | 带时区 ISO 8601 或 Unix 秒/毫秒；缺失表示无日期，不假造当前时间 |
| intensity | 0–1，默认 0.5，参与标记优先顺序与详情权重显示；不是风险等级 |
| source | 用户提供的来源名称，可不填；不会自动声称在线 |
| description | 纯文本，可选 |
| url | HTTP(S) 关联链接，可选；不接受 javascript/data 链接 |

例：

```json
[
  {"id":"p-1","title":"示例地点（虚构）","lat":31.23,"lng":121.47,"location":"上海","category":"展示组 A","description":"虚构记录，仅演示坐标展示"}
]
```

面板“字段映射 / 数组路径”接受：

```json
{
  "dataPath":"data.items",
  "fields": {
    "title":"name",
    "lat":"geo.latitude",
    "lng":"geo.longitude",
    "category":"group",
    "timestamp":"created_at"
  }
}
```

这适用于 `{ "data": { "items": [...] } }` 响应；顶层数组省略 `dataPath`。嵌套字段用点路径。CSV 映射到表头文本；不要设置数组路径。JSON 文件也支持相同配置。加载不同结构文件前清空或调整旧映射。

最多 10 MiB / 10,000 条；整个批次校验成功才替换当前数据。不静默丢弃无效行。地球最多绘制按日期、权重排序的 180 条；列表可加载更多，面板说明该限制。分类和时间筛选可缩小绘制范围。

时间滑块是累积截止时间：最早到最晚，无日期记录始终保留。导入新文件重置为全部时间，API 刷新保留筛选比例。页面刷新后不保留导入数据、API URL 或映射配置；需要持久化时由用户另行要求。

API 为 GET，默认不带认证和跨域 cookie；支持浏览器允许的 HTTP(S) 地址及同源相对路径，20 秒超时。错误不回退到示例数据；保留旧数据并标记失败，轮询失败后停止自动刷新，手动重连成功后恢复。导入文件或更改连接参数也会停止原有轮询。生产 HTTPS 页面不能直接请求 HTTP API；跨域需 CORS。敏感凭证须用服务端代理管理。

现阶段只连接一个当前数据集；如需合并多源，应在适配层统一格式、保证跨源 ID 唯一，再传入渲染层。不包含分页自动拉全、WebSocket、地址解析或自动网页抓取。
