# 验证清单

1. `npm ci`、`npm run build`、`npm test`。测试真实转换结果和 HTTP loader；不要只测试文件名或实现文本。
2. 空白启动：地球、星空、光晕与玻璃面板可见，0 条记录，无新闻样本、默认 API 或假在线状态。
3. 主动导入 `public/examples/locations.json`：4 条虚构地点、2 类，自定义分类/颜色、地点标签与详情有效。
4. 导入 `locations.csv`：同样成功，历史记录可见；时间筛选排除晚于截止时间的记录，缺失时间记录保留。经纬度 0,0 不被替换。
5. API：同源 `/examples/locations.json` GET 成功；用临时本地 fixture 测试空数组、嵌套字段、HTTP 错误、无效响应、取消及流式体积上限。跨域是否成功取决于实际服务的 CORS，不把本机 fixture 测试称为任意外部 API 验证。
6. 故障：显示具体错误，不生成演示记录、不声称在线。清空可取消请求并停止刷新；清空后慢响应不可重新灌入数据。
7. 桌面及窄屏观察地球与面板。若需 GUI 控制，使用当前环境支持的浏览器工具，不编写未获授权的系统自动化。
8. 打包只包含新 Skill 与模板：无 `.git`、`node_modules`、`.env`、数据库、新闻缓存、用户数据或构建输出。预览构建可以保留在开发副本但不进入分享包。
